# Full Stack Development Training Forms

This repository contains two simple HTML form examples used for learning basic front-end form structure and input handling.

## Files

- `form1.html` - A simple contact form with fields for name and email, plus a submit button.
- `registration.html` - A student registration form for a university use case, including fields for first name, last name, email, phone, date of birth, roll number, address, password, and confirm password.

## Purpose

The project demonstrates:

- Basic HTML form markup
- Use of different input types (`text`, `email`, `tel`, `date`, `password`)
- Required fields using the `required` attribute
- Form layout using `label`, `input`, `textarea`, and `fieldset`

## How to Use

1. Open `form1.html` or `registration.html` in a web browser.
2. Fill out the form fields.
3. Click the **Submit** or **Register** button.

## Notes

- These forms are static examples and do not currently include client-side validation or server-side processing.
- You can extend them by adding CSS for styling or JavaScript for validation and form submission handling.
